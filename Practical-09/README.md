# Practical No. 9

## Title
Graph Traversal for Campus Navigation Using BFS and DFS

## Problem Statement

Design a navigation system for a campus consisting of multiple buildings. The system should explore possible paths between buildings using graph traversal techniques.

Represent the campus as a graph using an adjacency matrix and implement Breadth-First Search (BFS) and Depth-First Search (DFS) to explore building connectivity.

## Objectives

- To understand graph representation using adjacency matrices.
- To implement Breadth-First Search (BFS) traversal.
- To implement Depth-First Search (DFS) traversal.
- To understand graph traversal techniques.
- To simulate a real-world campus navigation system using graph theory.
- To develop skills in exploring and analyzing connectivity between nodes.
- To understand the use of queues and stacks in graph traversal.
