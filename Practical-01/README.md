# Practical No. 1

## Title
Program to display different patterns using numbers, alphabets, and asterisks.


## Algorithms

### 1. Right-angle Triangle with Numbers
1. Start.
2. Input the number of rows `n`.
3. Repeat for each row from `1` to `n`.
4. Print numbers from `1` to the current row number.
5. Stop.

### 2. Diamond Shape with Numbers
1. Start.
2. Input the number of rows `n`.
3. Print the upper half of the diamond.
4. Print the lower half of the diamond.
5. Use spaces and numbers to form the diamond shape.
6. Stop.

### 3. Pyramid with Asterisks
1. Start.
2. Input the number of rows `n`.
3. Print spaces before the asterisks.
4. Print asterisks according to the row number.
5. Repeat until all rows are printed.
6. Stop.

### 4. Pyramid Using Alphabets
1. Start.
2. Input the number of rows `n`.
3. Print spaces before the alphabets.
4. Print alphabets in increasing and decreasing order.
5. Repeat for all rows.
6. Stop.
